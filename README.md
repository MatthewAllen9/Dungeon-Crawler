# Dungeon Crawler

Date:  March 27, 2026

## Multi-Language Game System (C & Python)
Treasure Runner is a modular dungeon crawler game developed as part of a CIS2750 assignment, combining a high-performance C backend with a Python-based user interface. The project emphasizes software architecture, cross-language integration, testing, and maintainability.

## Overview
This project features:

+ C Backend: Core game logic, world management, player movement, puzzle systems, and performance-critical functionality
+ Python UI: Interactive terminal-based frontend built with curses for rendering, player interaction, and game state visualization
ctypes Integration: Seamless communication between Python and C layers
+ MVC-Inspired Structure: Separation of concerns across models, controllers, and UI components

## Key Features
+ Procedurally loaded dungeon worlds from .ini configuration files
+ Dynamic room traversal, treasure collection, portals, and puzzle mechanics
+ Player profiles with persistent progress tracking
+ Real-time terminal UI with status bars, game messages, and room rendering
+ Configurable controls and game resets
+ Extensive validation for edge cases and user input
