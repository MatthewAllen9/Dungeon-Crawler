# Dungeon Crawler

Date:  March 27, 2026

## Multi-Language Game System (C & Python)
Treasure Runner is a modular dungeon crawler game developed as part of a CIS2750 assignment, combining a high-performance C backend with a Python-based user interface. The project emphasizes software architecture, cross-language integration, testing, and maintainability.

+ Designed a modular game system using a C backend and a Python interface using ctypes
+ Used Claude Code and structured prompting to accelerate debugging, refine implementation strategies, and generate test scenarios for UI and system validation
Implemented unit, integration, functional, and regression testing with CI/CD pipelines to maintain code quality and ensure stable releases
Produced clear technical documentation and validation workflows to support maintainability and long-term scalability
